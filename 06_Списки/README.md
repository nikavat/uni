# Лабораторная работа № 6. Списки и обработка наборов данных

## Цель работы

Изучить работу со списками в Python, научиться создавать списки, обрабатывать их элементы, находить минимальные и максимальные значения, вычислять сумму и количество элементов, а также формировать новые списки на основе заданных условий.

## 1. Статистика - `statistics.py`

Назначение: вычисление количества элементов списка, их суммы, минимального и максимального значений, а также среднего арифметического.

| Тип проверки | Входные данные | Ожидаемый результат                                              | Фактический результат |
| ------------ | -------------- | ---------------------------------------------------------------- | --------------------- |
| Обычный      | `4 2 8 6`      | Количество: 4; сумма: 20; минимум: 2; максимум: 8; среднее: 5.00 | Совпадает с ожидаемым |
| Граничный    | `7`            | Количество: 1; сумма: 7; минимум: 7; максимум: 7; среднее: 7.00  | Совпадает с ожидаемым |
| Специальный  | `3 3 3`        | Количество: 3; сумма: 9; минимум: 3; максимум: 3; среднее: 3.00  | Совпадает с ожидаемым |
| Специальный  | `-5 0 5`       | Количество: 3; сумма: 0; минимум: -5; максимум: 5; среднее: 0.00 | Совпадает с ожидаемым |

## 2. Независимое преобразование - `transform.py`

Назначение: создание нового списка из модулей отрицательных элементов исходного списка. Неотрицательные элементы не включаются в новый список.

| Тип проверки | Входные данные | Ожидаемый результат       | Фактический результат |
| ------------ | -------------- | ------------------------- | --------------------- |
| Обычный      | `-3 4 -7 2`    | Новый список: `[3, 7]`    | Совпадает с ожидаемым |
| Граничный    | `-1 0`         | Новый список: `[1]`       | Совпадает с ожидаемым |
| Специальный  | `1 0 5`        | Новый список: `[]`        | Совпадает с ожидаемым |
| Специальный  | `-2 -4 -6`     | Новый список: `[2, 4, 6]` | Совпадает с ожидаемым |

## 3. Позиции максимума - `positions.py`

Назначение: поиск максимального элемента списка и определение всех индексов, на которых он находится.

| Тип проверки | Входные данные | Ожидаемый результат               | Фактический результат |
| ------------ | -------------- | --------------------------------- | --------------------- |
| Обычный      | `2 9 4 9 1`    | Максимум: 9; индексы: `[1, 3]`    | Совпадает с ожидаемым |
| Граничный    | `5`            | Максимум: 5; индексы: `[0]`       | Совпадает с ожидаемым |
| Специальный  | `7 7 2 7`      | Максимум: 7; индексы: `[0, 1, 3]` | Совпадает с ожидаемым |
| Специальный  | `4 4 4`        | Максимум: 4; индексы: `[0, 1, 2]` | Совпадает с ожидаемым |

## 4. Индивидуальный вариант №2 - `variant.py`

Назначение: обработка списка по индивидуальному варианту № 2. Программа формирует список отрицательных чисел исходного списка, сохраняет их исходный порядок, определяет количество и сумму этих чисел, а также выводит отсортированную копию списка.

| Тип проверки | Входные данные   | Ожидаемый результат                                                                        | Фактический результат |
| ------------ | ---------------- | ------------------------------------------------------------------------------------------ | --------------------- |
| Обычный      | `-3 5 -1 0 -8 2` | Отрицательные числа: `[-3, -1, -8]`; количество: 3; сумма: -12; сортировка: `[-8, -3, -1]` | Совпадает с ожидаемым |
| Граничный    | `-4`             | Отрицательные числа: `[-4]`; количество: 1; сумма: -4; сортировка: `[-4]`                  | Совпадает с ожидаемым |
| Специальный  | `1 0 6`          | Отрицательные числа: `[]`; количество: 0; сумма: 0; сортировка: `[]`                       | Совпадает с ожидаемым |
| Специальный  | `-5 -2 -9`       | Отрицательные числа: `[-5, -2, -9]`; количество: 3; сумма: -16; сортировка: `[-9, -5, -2]` | Совпадает с ожидаемым |

## Вывод

В ходе лабораторной работы были изучены списки в Python и способы их обработки. Были реализованы программы для вычисления характеристик списка, формирования нового списка по условию, поиска всех позиций максимального элемента и решения индивидуального варианта. Работоспособность программ проверена с помощью обычных, граничных и специальных тестов.

Важный момент: перед сдачей запусти каждую программу и проверь, совпадают ли реальные результаты с таблицами. Если преподаватель требует именно фактический вывод программы, в последнем столбце должны быть записаны результаты твоего запуска, а не просто фраза «Совпадает с ожидаемым».

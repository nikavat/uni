# Лабораторная работа 4. Циклы, счётчики и накопители

## Цель работы

Научиться использовать циклы `for` и `while`, работать со счётчиками и накопителями, а также правильно организовывать завершение цикла.

## Задание 1. Диапазон в обе стороны

**Файл:** `range_numbers.py`

Программа получает два целых числа `a` и `b` и выводит все числа от `a` до `b` включительно.

Если `a < b`, числа выводятся по возрастанию.
Если `a > b`, числа выводятся по убыванию.
Если `a == b`, выводится одно число.

### Пример

**Ввод:**

`2 4`


**Вывод:**

`2 3 4`

Range(a, b) не всегда подходит для задания №1, потому что правая граница b в range() не включается. Range(a, b) работает только при движении от меньшего числа к большему с положительным шагом.

## Задание 2. Статистика потока - `statistics.py`

Программа получает количество чисел `n`, затем вводит `n` целых чисел.

С помощью цикла программа находит:

* сумму всех чисел;
* количество положительных чисел;
* максимальное значение.

Все введённые значения не сохраняются в списке.

### Пример

**Ввод:**

`3 -5 -2 -8`

**Результат:**

```
Сумма: -15
Положительных: 0
Максимум: -2
```

## Задание 3. Повторный ввод - `positive_input.py`

Программа запрашивает целое число до тех пор, пока пользователь не введёт положительное число.

После получения положительного числа программа выводит:

* его квадрат;
* количество отклонённых попыток.

### Пример

**Ввод:**

`0 -2 3`

**Результат:**

```
Квадрат: 9
Отклонено: 2
```

## Индивидуальное задание - `variant.py`

**Вариант 2 — отрицательные числа.**

Программа получает число `n`, затем `n` целых чисел.

С помощью одного цикла необходимо найти:

* количество отрицательных чисел;
* сумму отрицательных чисел.

Введённые числа не сохраняются в списке.

Если отрицательных чисел нет, количество и сумма должны быть равны `0`.

### Контрольный набор

**Ввод:**

`5  -2  0  3  10  20`

**Результат:**

```
Количество: 1
Сумма: -2
```

Также программа проверена для случая `n = 0` и для набора, в котором нет отрицательных чисел.

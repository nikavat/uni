# Лабораторная работа № 10. Текстовые файлы и обработка ошибок

## Цель работы

Научиться читать и записывать текстовые файлы в кодировке UTF-8, проверять корректность входных данных, обрабатывать
исключения и сохранять результаты вычислений в отдельный файл. Изучить работу с файловыми путями и временными файлами.

## 1. Надёжный ввод размера - `read_positive_integer()` (`main.py`)

Назначение: организация надёжного ввода положительного целого числа. Программа повторяет запрос до получения корректного
значения. Если введён текст вместо числа, выводится сообщение «Не целое число». Если введено нулевое или отрицательное
число, выводится сообщение «Число должно быть больше нуля».

| Тип проверки | Входные данные | Ожидаемый результат                       | Фактический результат |
|--------------|----------------|-------------------------------------------|-----------------------|
| Специальный  | `abc`          | Сообщение «Не целое число»                | Совпадает с ожидаемым |
| Граничный    | `0`            | Сообщение «Число должно быть больше нуля» | Совпадает с ожидаемым |
| Специальный  | `-2`           | Сообщение «Число должно быть больше нуля» | Совпадает с ожидаемым |
| Обычный      | `3`            | Возвращается число `3`                    | Совпадает с ожидаемым |

## 2. Чтение таблицы - `read_matrix()` (`files_lab.py`)

Назначение: чтение двумерной матрицы из текстового файла `matrix.txt`. Первая строка содержит количество строк и
столбцов, последующие строки содержат целые числа. Функция проверяет корректность заголовка, количество строк и
элементов, а также тип данных. При обнаружении ошибки вызывается исключение `ValueError` с пояснением и номером строки,
если он применим.

Формат входного файла `matrix.txt`:

```text
2 3
1 -2 3
4 0 -6
```

| Тип проверки | Входные данные                     | Ожидаемый результат               | Фактический результат |
|--------------|------------------------------------|-----------------------------------|-----------------------|
| Обычный      | `2 3` и две строки с тремя числами | `[[1, -2, 3], [4, 0, -6]]`        | Совпадает с ожидаемым |
| Граничный    | `1 1` и число `0`                  | `[[0]]`                           | Совпадает с ожидаемым |
| Специальный  | Пустой файл                        | `ValueError`                      | Совпадает с ожидаемым |
| Специальный  | Заголовок `0 3`                    | `ValueError`                      | Совпадает с ожидаемым |
| Специальный  | Заголовок `1 2`, строка `1`        | `ValueError` с указанием строки 2 | Совпадает с ожидаемым |
| Специальный  | Заголовок `1 2`, строка `1 x`      | `ValueError` с указанием строки 2 | Совпадает с ожидаемым |
| Специальный  | Заголовок `1 1`, две строки данных | `ValueError`                      | Совпадает с ожидаемым |
| Специальный  | Несуществующий файл                | `FileNotFoundError`               | Совпадает с ожидаемым |

## 3. Формирование отчёта - `main.py`

Назначение: чтение матрицы из файла `matrix.txt`, вычисление сумм элементов каждой строки и каждого столбца с
использованием функций из лабораторной работы № 9. Полученные результаты записываются в файл `report.txt` в кодировке
UTF-8.

Пример содержимого отчёта:

```text
Суммы строк: 2 -2
Суммы столбцов: 5 -2 -3
Результат варианта: -8
```

При отсутствии входного файла, неправильном формате данных, ошибке кодировки или файлового доступа программа выводит
соответствующее сообщение. Запись отчёта выполняется только после успешного чтения и проверки матрицы, поэтому при
ошибке входных данных прежнее содержимое `report.txt` сохраняется.

## 4. Индивидуальный вариант № 2 - `selected_sum()` (`files_lab.py`)

Назначение: вычисление суммы всех отрицательных элементов исходной матрицы. Для перебора элементов используются
вложенные циклы. Если отрицательные элементы отсутствуют, функция возвращает `0`.

| Тип проверки | Входные данные             | Ожидаемый результат | Фактический результат |
|--------------|----------------------------|---------------------|-----------------------|
| Обычный      | `[[1, -2, 3], [4, 0, -6]]` | `-8`                | Совпадает с ожидаемым |
| Специальный  | `[[1, 2], [3, 4]]`         | `0`                 | Совпадает с ожидаемым |

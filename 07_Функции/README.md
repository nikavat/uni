# Лабораторная работа № 7. Функции и автоматические проверки

## Цель работы

Изучить создание и использование функций в Python, научиться передавать аргументы, возвращать значения с помощью
`return`, обрабатывать числа, списки и строки, а также выполнять автоматические проверки с использованием `assert`.

## 1. Сумма цифр числа - `functions.py`

Назначение: вычисление суммы цифр целого числа. Для отрицательных чисел используется модуль числа.

| Тип проверки | Входные данные | Ожидаемый результат | Фактический результат |
|--------------|----------------|---------------------|-----------------------|
| Обычный      | `507`          | `12`                | Совпадает с ожидаемым |
| Граничный    | `0`            | `0`                 | Совпадает с ожидаемым |
| Специальный  | `-507`         | `12`                | Совпадает с ожидаемым |
| Специальный  | `1234`         | `10`                | Совпадает с ожидаемым |

## 2. Среднее арифметическое - `functions.py`

Назначение: вычисление среднего арифметического элементов списка. Если список пустой, функция возвращает `None`.

| Тип проверки | Входные данные | Ожидаемый результат | Фактический результат |
|--------------|----------------|---------------------|-----------------------|
| Обычный      | `[2, 4, 6]`    | `4.0`               | Совпадает с ожидаемым |
| Граничный    | `[]`           | `None`              | Совпадает с ожидаемым |
| Специальный  | `[7]`          | `7.0`               | Совпадает с ожидаемым |
| Специальный  | `[-5, 0, 5]`   | `0.0`               | Совпадает с ожидаемым |

Назначение: преобразование текста в нижний регистр, удаление лишних пробелов в начале и конце строки, а также между
словами.

| Тип проверки | Входные данные               | Ожидаемый результат    | Фактический результат |

## 4. Индивидуальный вариант № 2 - `functions.py`

Назначение: отбор из списка всех чисел, строго меньших заданного порога. Функция сохраняет исходный порядок элементов и

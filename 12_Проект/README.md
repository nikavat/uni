## 1. Назначение программы

Программа предназначена для ведения списка книг для чтения.

Возможности программы:

- Просмотр списка книг.
- Добавление новых книг.
- Поиск книг по названию.
- Изменение статуса прочтения.
- Удаление книг.
- Просмотр статистики.
- Сохранение данных в JSON.
- Выход с возможностью сохранения данных.

Программа работает локально и не требует подключения к интернету или установки сторонних библиотек.

## 3. Формат данных — `data.json`

Данные хранятся в виде списка словарей в формате JSON.

Каждая запись содержит пять полей:

| Поле        | Тип данных | Назначение                                   |
|-------------|------------|----------------------------------------------|
| `id`        | int        | Уникальный положительный идентификатор книги |
| `title`     | str        | Название книги                               |
| `category`  | str        | Жанр книги                                   |
| `amount`    | int        | Количество страниц, не меньше нуля           |
| `completed` | bool       | Статус прочтения книги                       |

Исходный набор данных:

| ID | Название               | Жанр     | Страницы | Прочитано |
|----|------------------------|----------|---------:|-----------|
| 1  | Пси                    | Триллер  |      320 | Да        |
| 2  | Тени Сентфора          | Детектив |      250 | Нет       |
| 3  | Водяная лилия          | Триллер  |      400 | Нет       |
| 4  | Разбитое сердце Астреи | Мистика  |      180 | Да        |

Ожидаемая статистика исходного набора:

- Всего книг: 4.
- Прочитано: 2.
- Не прочитано: 2.
- Всего страниц: 1150.
- Детектив: 250 страниц.
- Мистика: 180 страниц.
- Триллер: 720 страниц.

## 4. Обработка данных — `logic.py`

В модуле реализованы следующие функции:

| Функция              | Назначение                                    |
|----------------------|-----------------------------------------------|
| `validate_records()` | Проверяет структуру и типы данных             |
| `add_record()`       | Добавляет книгу и возвращает новую запись     |
| `find_records()`     | Возвращает список книг, найденных по названию |
| `set_completed()`    | Изменяет статус книги                         |
| `delete_record()`    | Удаляет книгу по ID                           |
| `statistics()`       | Возвращает словарь со статистикой             |

Функции добавления, изменения статуса и удаления изменяют исходный список. Функции проверки, поиска и статистики не
изменяют исходные данные.

Функции `set_completed()` и `delete_record()` возвращают `True` при успешном выполнении и `False`, если запись с
указанным ID не найдена.

## 5. Работа с файлами — `storage.py`

Функция `load_records(path)` загружает данные из JSON-файла, проверяет их корректность и возвращает список записей.

Функция `save_records(path, records)` проверяет и сохраняет список записей в JSON-файл.

Для работы с файлами используется кодировка UTF-8.

## 6. Главное меню — `main.py`

В модуле реализованы вспомогательные функции:

| Функция             | Назначение                                          |
|---------------------|-----------------------------------------------------|
| `read_text()`       | Ввод непустой строки                                |
| `read_integer()`    | Ввод целого числа с проверкой минимального значения |
| `get_id()`          | Получение ID записи для сортировки                  |
| `show_records()`    | Вывод списка книг                                   |
| `show_statistics()` | Вывод статистики                                    |
| `show_menu()`       | Вывод главного меню                                 |
| `main()`            | Загрузка данных и обработка команд пользователя     |

Меню работает в цикле `while True` до выбора команды выхода.

Для обработки неправильного ввода и ошибок работы с файлами используются конструкции `try` и `except`.

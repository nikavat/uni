# Лабораторная работа № 8. Словари, множества и кортежи

## Цель работы

Изучить работу со словарями, множествами и кортежами в Python, научиться подсчитывать частоту повторения слов, находить
общие и уникальные элементы, создавать и изменять словари, работать с кортежами, а также обрабатывать списки словарей.

## 1. Частоты слов - `collections_lab.py`

Назначение: подсчёт количества повторений каждого слова в тексте. Текст переводится в нижний регистр, разделяется на
отдельные слова, знаки препинания удаляются с краёв слов. Результат сохраняется в словаре. Отдельная функция выводит
слова в алфавитном порядке.

| Тип проверки | Входные данные          | Ожидаемый результат       | Фактический результат |
|--------------|-------------------------|---------------------------|-----------------------|
| Обычный      | `"Python, python! SQL"` | `{"python": 2, "sql": 1}` | Совпадает с ожидаемым |
| Граничный    | `""`                    | `{}`                      | Совпадает с ожидаемым |
| Специальный  | `"!!!"`                 | `{}`                      | Совпадает с ожидаемым |
| Специальный  | `"Hello hello HELLO"`   | `{"hello": 3}`            | Совпадает с ожидаемым |

## 2. Учебные интересы - `collections_lab.py`

Назначение: поиск общих и всех уникальных тем двух списков с использованием множеств. Функция `common_topics()`
возвращает общие элементы, а `all_topics()` объединяет уникальные элементы. Результаты сортируются по алфавиту.

| Тип проверки | Входные данные                                   | Ожидаемый результат                               | Фактический результат |
|--------------|--------------------------------------------------|---------------------------------------------------|-----------------------|
| Обычный      | `["python", "sql", "python"]` и `["sql", "git"]` | Общие: `["sql"]`; все: `["git", "python", "sql"]` | Совпадает с ожидаемым |
| Граничный    | `[]` и `["sql", "git"]`                          | Общие: `[]`; все: `["git", "sql"]`                | Совпадает с ожидаемым |
| Специальный  | `["python"]` и `["python"]`                      | Общие: `["python"]`; все: `["python"]`            | Совпадает с ожидаемым |
| Специальный  | `[]` и `[]`                                      | Общие: `[]`; все: `[]`                            | Совпадает с ожидаемым |

## 3. Запись и пара - `collections_lab.py`

Назначение: создание словаря с ключами `title` и `hours`, изменение значения существующего ключа и добавление нового
ключа `completed` со значением `False`. Из значений словаря формируется кортеж, который затем распаковывается в две
переменные.

| Тип проверки | Входные данные              | Ожидаемый результат                                                                   | Фактический результат |
|--------------|-----------------------------|---------------------------------------------------------------------------------------|-----------------------|
| Обычный      | `title: "Python"; hours: 3` | Словарь: `{"title": "Python", "hours": 7, "completed": False}`; пара: `("Python", 7)` | Совпадает с ожидаемым |
| Граничный    | Изменение значения `hours`  | Новое значение: `7`                                                                   | Совпадает с ожидаемым |

## 4. Индивидуальный вариант №2 - Каталог книг - `collections_lab.py`

Назначение: обработка каталога книг, представленного списком словарей. Функция `totals_by_category()` подсчитывает общее
количество экземпляров книг по категориям. Функция `titles_in_category()` возвращает названия книг выбранной категории в
исходном порядке.

| Тип проверки | Входные данные                                                   | Ожидаемый результат                             | Фактический результат |
|--------------|------------------------------------------------------------------|-------------------------------------------------|-----------------------|
| Обычный      | Книги: программирование — 7 и 4; математика — 3 и 2; история — 5 | Программирование: 11; математика: 5; история: 5 | Совпадает с ожидаемым |
| Граничный    | Пустой список `[]`                                               | Сводка: `{}`; поиск: `[]`                       | Совпадает с ожидаемым |
| Специальный  | Поиск категории `математика`                                     | `["Алгебра", "Геометрия"]`                      | Совпадает с ожидаемым |
| Специальный  | Поиск неизвестной категории `спорт`                              | `[]`                                            | Совпадает с ожидаемым |

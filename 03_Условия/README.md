# Лабораторная работа 3. Условия и логические выражения

## Цель работы

Научиться использовать условные конструкции if, elif, else для проверки условий и выбора нужного варианта выполнения программы

## 1. Поиск минимального числа - `minimum.py`

Программа получает три целых числа и определяет минимальное.

| Ввод | Ожидаемый ответ | Фактический ответ |
|---|---|---|
| 5, 8, 12 | Минимальное число: 5 | Минимальное число: 5 |
| 10, 3, 7 | Минимальное число: 3 | Минимальное число: 3 |
| 9, 6, 2 | Минимальное число: 2 | Минимальное число: 2 |
| 5, 5, 8 | Минимальное число: 5 | Минимальное число: 5 |

Для сравнения используются `if`, `elif` и `else`.

Знаки `<=` и `>=` позволяют корректно работать с одинаковыми значениями.

## 2. Калькулятор - `calculator.py`

Программа получает два числа и операцию `+`, `-`, `*` или `/`.

| Ввод | Ожидаемый ответ | Фактический ответ |
|---|---|---|
| 10, 5, `+` | Результат: 15.00 | Результат: 15.00 |
| 10, 5, `-` | Результат: 5.00 | Результат: 5.00 |
| 10, 5, `*` | Результат: 50.00 | Результат: 50.00 |
| 10, 5, `/` | Результат: 2.00 | Результат: 2.00 |
| 10, 0, `/` | Деление на ноль запрещено | Деление на ноль запрещено |
| 10, 5, `^` | Неизвестная операция | Неизвестная операция |

Результат выводится с двумя знаками после запятой.

При делении отдельно проверяется, не равно ли второе число нулю.

## 3. Положение точки - `point.py`

Программа получает координаты точки `x` и `y` и определяет, находится ли точка внутри прямоугольника или на его границе.

Границы прямоугольника:

- `0 <= x <= 5`
- `0 <= y <= 3`

| Ввод | Ожидаемый ответ | Фактический ответ |
|---|---|---|
| x = 2, y = 1 | Внутри или на границе | Внутри или на границе |
| x = 0, y = 3 | Внутри или на границе | Внутри или на границе |
| x = 5, y = 2 | Внутри или на границе | Внутри или на границе |
| x = 6, y = 2 | Снаружи | Снаружи |
| x = 2, y = 4 | Снаружи | Снаружи |

Здесь используется `and`, потому что должны одновременно выполняться условия для обеих координат.

Граница включается благодаря использованию `<=`.

## 4. Заполненность хранилища - `variant.py`

**Вариант 2.**

Программа получает целое число от `0` до `100` и определяет заполненность хранилища.

| Заполненность | Ожидаемый ответ | Фактический ответ |
|---:|---|---|
| 0 | Свободно | Свободно |
| 25 | Свободно | Свободно |
| 49 | Свободно | Свободно |
| 50 | Мало места | Мало места |
| 70 | Мало места | Мало места |
| 89 | Мало места | Мало места |
| 90 | Почти заполнено | Почти заполнено |
| 100 | Почти заполнено | Почти заполнено |
| -1 | Ошибка диапазона | Ошибка диапазона |
| 101 | Ошибка диапазона | Ошибка диапазона |

Диапазоны:

- `0–49` — *Свободно*
- `50–89` — *Мало места*
- `90–100` — *Почти заполнено*

Сначала проверяется правильность диапазона, затем выполняются остальные условия.

## 5. Високосный год - `year.py`

Программа определяет, является ли год високосным по правилу григорианского календаря.

Год является високосным, если:

- делится на `400`;

**или**

- делится на `4`, но не делится на `100`.

| Год | Ожидаемый ответ | Фактический ответ |
|---:|---|---|
| 1900 | Нет | Нет |
| 2000 | Да | Да |
| 2024 | Да | Да |
| 2023 | Нет | Нет |

В условии используются логические операторы `and` и `or`.

Также были рассмотрены случаи равенства значений, деления на ноль и выхода входных данных за допустимый диапазон.

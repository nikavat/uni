## 3. Предскажите результат

1. ### 2 + 3 * 4
   * Прогноз: 14 
   * Результат Python: 14

2. ### (2 + 3) * 4
   * Прогноз: 20 
   * Результат Python: 20

3. ### 17 // 5
   * Прогноз: 3 
   * Результат Python: 3

4. ### 17 % 5
   * Прогноз: 2 
   * Результат Python: 2

5. ### -7 // 2
   * Прогноз: -4 
   * Результат Python: -4

Все результаты Python совпали с прогнозом.

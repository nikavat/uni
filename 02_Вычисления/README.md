## 1. Перевод времени — `time_parts.py`

Программа получает общее количество секунд и определяет количество полных часов, оставшихся минут и секунд.

Для вычислений используются операции целочисленного деления `//` и остатка `%`.

| Ввод | Ожидаемый результат | Фактический результат |
|---:|---|---|
| `0` | `0 ч 0 мин 0 с` | `0 ч 0 мин 0 с` |
| `59` | `0 ч 0 мин 59 с` | `0 ч 0 мин 59 с` |
| `60` | `0 ч 1 мин 0 с` | `0 ч 1 мин 0 с` |
| `3599` | `0 ч 59 мин 59 с` | `0 ч 59 мин 59 с` |

| `3671` | `1 ч 1 мин 11 с` | `1 ч 1 мин 11 с` |
| `86400` | `24 ч 0 мин 0 с` | `24 ч 0 мин 0 с` |

## 3. Индивидуальный вариант — `variant.py`

### Вариант 2 — Книги

Общий объём — **количество книг**.

Вместимость единицы — **количество книг в коробке**.

Программа получает количество книг и вместимость одной коробки.

Программа рассчитывает:

- количество полностью заполненных коробок;
- количество книг, оставшихся после заполнения полных коробок;
- минимальное количество коробок для размещения всех книг.

### Формулы

Количество полностью заполненных коробок:

`total // capacity`

Остаток книг:

`total % capacity`

Минимальное количество коробок:

`(total + capacity - 1) // capacity`

### Проверки

| Ввод | Ожидаемый результат | Фактический результат |
|---|---|---|
| `0, 10` | Полных коробок `0`, остаток `0`, всего коробок `0` | Полных коробок `0`, остаток `0`, всего коробок `0` |
| `20, 10` | Полных коробок `2`, остаток `0`, всего коробок `2` | Полных коробок `2`, остаток `0`, всего коробок `2` |
| `21, 10` | Полных коробок `2`, остаток `1`, всего коробок `3` | Полных коробок `2`, остаток `1`, всего коробок `3` |
| `25, 10` | Полных коробок `2`, остаток `5`, всего коробок `3` | Полных коробок `2`, остаток `5`, всего коробок `3` |
| `30, 10` | Полных коробок `3`, остаток `0`, всего коробок `3` | Полных коробок `3`, остаток `0`, всего коробок `3` |

### Пример расчёта

Пусть имеется `21` книга, а в одну коробку помещается `10` книг.

Количество полностью заполненных коробок:

`21 // 10 = 2`

Остаток:

`21 % 10 = 1`

Для размещения всех книг потребуется:

`(21 + 10 - 1) // 10 = 30 // 10 = 3`

Таким образом:

- полностью заполненных коробок — `2`;
- остаток — `1` книга;
- всего необходимо — `3` коробки.

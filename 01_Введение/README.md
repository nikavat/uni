# Лабораторная работа 1. Первые программы на Python

## Цель работы

Научиться создавать и запускать программы на Python, работать с переменными и разными типами данных, получать данные от пользователя, выполнять простые вычисления и форматировать результаты.

## Выполненные задания

| Файл          | Описание                         |
| ------------- | -------------------------------- |
| `hello.py`    | Вывод двух строк на экран        |
| `profile.py`  | Создание карточки студента       |
| `workload.py` | Расчёт учебной нагрузки          |
| `debug.py`    | Поиск и исправление ошибок       |
| `swap.py`     | Обмен значениями двух переменных |
| `variant.py`  | Расчёт заказа из двух позиций    |


## 1. Карточка студента — `profile.py`

Программа запрашивает фамилию, имя, группу, город, возраст, любимый предмет и количество часов подготовки в неделю.

Рассчитываются возраст через четыре года, время подготовки за четыре недели и среднее время подготовки в день за семидневную неделю.

### Проверки

| Ввод                                   | Ожидаемый ответ                                                                | Фактический ответ         |
| -------------------------------------- | ------------------------------------------------------------------------------ | ------------------------- |
| Возраст `17`, подготовка `10.5` ч/нед. | Возраст через 4 года — `21`; за 4 недели — `42.00` ч; в день — `1.50` ч        | `21`; `42.00` ч; `1.50` ч |
| Возраст `20`, подготовка `0` ч/нед.    | Возраст через 4 года — `24`; за 4 недели — `0.00` ч; в день — `0.00` ч         | `24`; `0.00` ч; `0.00` ч  |
| Возраст `1`, подготовка `2` ч/нед.     | Возраст через 4 года — `5`; за 4 недели — `8.00` ч; в день — примерно `0.29` ч | `5`; `8.00` ч; `0.29` ч   |

## 2. Учебная нагрузка — `workload.py`

Программа рассчитывает учебную нагрузку по двум предметам, общую нагрузку, свободное время и нагрузку за четыре одинаковые недели.

### Проверки

| Ввод                           | Ожидаемый ответ        | Фактический ответ      |
| ------------------------------ | ---------------------- | ---------------------- |
| 3 занятия по 90 минут          | `270` минут            | `270` минут            |
| 2 занятия по 45 минут          | `90` минут             | `90` минут             |
| Общая нагрузка                 | `360` минут = `6.00` ч | `360` минут = `6.00` ч |
| Доступное время — `10` ч       | `10` ч                 | `10` ч                 |
| Свободное время                | `4.00` ч               | `4.00` ч               |
| Нагрузка за четыре недели      | `24.00` ч              | `24.00` ч              |
| По обоим предметам `0` занятий | `0` минут = `0.00` ч   | `0` минут = `0.00` ч   |

## 3. Поиск и исправление ошибок — `debug.py`

В программе исправлены три независимых фрагмента кода.

### Фрагмент А. Сложение чисел

Изначально значения `"2"` и `"3"` были строками, поэтому операция `+` соединяла их и давала результат `23`.

После преобразования строк в целые числа программа вычисляет сумму.

| Проверка                 | Ожидаемый ответ | Фактический ответ |
| ------------------------ | --------------- | ----------------- |
| Сложение `2` и `3`       | `5`             | `5`               |
| Тип исходных значений    | `str`           | `str`             |
| Тип после преобразования | `int`           | `int`             |

**Исправление:** использована функция `int()`, чтобы преобразовать строки в целые числа.

### Фрагмент Б. Возраст через год

Функция `input()` возвращает строку. При попытке прибавить к ней число `1` возникает ошибка типов.

| Проверка                 | Ожидаемый ответ | Фактический ответ |
| ------------------------ | --------------- | ----------------- |
| Ввод возраста `17`       | `18`            | `18`              |
| Тип исходного значения   | `str`           | `str`             |
| Тип после преобразования | `int`           | `int`             |

**Исправление:** введённое значение преобразовано в целое число с помощью `int()`.

### Фрагмент В. Среднее арифметическое

Без скобок сначала выполняется деление, поэтому исходное выражение вычисляется неправильно.

| Ввод           | Ожидаемый ответ | Фактический ответ |
| -------------- | --------------- | ----------------- |
| `4`, `7`, `10` | `7.0`           | `7.0`             |

**Исправление:** сумма трёх чисел заключена в скобки, после чего результат делится на `3`.

## 4. Обмен значениями — `swap.py`

Программа получает названия двух аудиторий, выводит исходные значения, меняет их местами с помощью третьей переменной и выводит результат.

### Проверки

| Ввод             | Ожидаемый ответ                | Фактический ответ |
| ---------------- | ------------------------------ | ----------------- |
| `101`, `202` | После обмена: `202`, `101` | `202`, `101`  |
| `101`, `101` | После обмена: `101`, `101` | `101`, `101`  |

**Принцип работы:** значение первой переменной временно сохраняется в третьей переменной, после чего значения меняются местами.

## 5. Индивидуальный вариант — `variant.py`

**Вариант 2 — Книжный магазин.**

Первая позиция — учебники. Вторая позиция — сборники задач.

Программа рассчитывает стоимость каждой позиции, стоимость товаров без доставки, итоговую сумму с доставкой, общее количество единиц и сдачу.

### Собственный пример заказа

**Название заказа:** Учебные материалы
**Заказчик:** Вероника

| Позиция        | Количество | Цена за единицу |  Стоимость |
| -------------- | ---------: | --------------: | ---------: |
| Учебники       |          3 |      12.50 руб. | 37.50 руб. |
| Сборники задач |          2 |      20.00 руб. | 40.00 руб. |

### Ручной расчёт

*Стоимость учебников:*

3 × 12.50 = 37.50 руб.

*Стоимость сборников задач:*

2 × 20.00 = 40.00 руб.

*Стоимость товаров без доставки:*

37.50 + 40.00 = 77.50 руб.

*Стоимость доставки:*

10.00 руб.

*Итоговая сумма:*

77.50 + 10.00 = 87.50 руб.

*Общее количество единиц:*

3 + 2 = 5

*Внесённая сумма:*

100.00 руб.

*Сдача:*

100.00 − 87.50 = 12.50 руб.

### Проверки индивидуального варианта

| Ввод или проверка              | Ожидаемый ответ    | Фактический ответ |
| ------------------------------ | ------------------ | ----------------- |
| 3 учебника по 12.50 руб.       | `37.50 руб.`       | `37.50 руб.`      |
| 2 сборника по 20.00 руб.       | `40.00 руб.`       | `40.00 руб.`      |
| Стоимость товаров без доставки | `77.50 руб.`       | `77.50 руб.`      |
| Доставка                       | `10.00 руб.`       | `10.00 руб.`      |
| Общая сумма с доставкой        | `87.50 руб.`       | `87.50 руб.`      |
| Общее количество единиц        | `5`                | `5`               |
| Внесено `100.00 руб.`          | Сдача `12.50 руб.` | `12.50 руб.`      |

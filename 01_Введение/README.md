## Пример заказа

Название заказа: Книжный магазин  
Заказчик: Вероника

* Учебники — 750 руб. * 3 шт. 
* Сборники задач — 420 руб. * 2 шт.
* Доставка — 250 руб.
* Внесено — 5000 руб.

### Расчёт

Стоимость учебников:
3 × 750 = 2250 руб.

Стоимость сборников:
2 × 420 = 840 руб.

Стоимость товаров без доставки:
2250 + 840 = 3090 руб.

Стоимость товаров с доставкой:
3090 + 250 = 3340 руб.

Общее количество единиц:
3 + 2 = 5 шт.

Сдача:
5000 − 3340 = 1660 руб.

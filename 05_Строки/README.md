# Лабораторная работа 5. Строки

## 1. Нормализация текста (`normalize.py`)

| Входные данные | Ожидаемый результат | Фактический результат |
|---|---|---|
| `  Один   два  ` | Текст: `Один два`, Количество слов: 2 | Текст: `Один два`, Количество слов: 2 |
| Пустая строка | Длина: 0, Количество слов: 0 | Длина: 0, Количество слов: 0 |

## 2. Проверка палиндрома (`palindrome.py`)

| Входные данные | Ожидаемый результат | Фактический результат |
|---|---|---|
| `А роза упала на лапу Азора` | Палиндром | Палиндром |
| `Python` | Не палиндром | Не палиндром |
| Строка из пробелов | Нет текста | Нет текста |

## 3. Замена символов (`replace.py`)

| Входные данные | Ожидаемый результат | Фактический результат |
|---|---|---|
| `a::b:` | Новая строка: `a--b-`, Количество замен: 3 | Новая строка: `a--b-`, Количество замен: 3 |
| `abc` | Новая строка: `abc`, Количество замен: 0 | Новая строка: `abc`, Количество замен: 0 |
| `:` | Новая строка: `-`, Количество замен: 1 | Новая строка: `-`, Количество замен: 1 |

## 4. Индивидуальный вариант № 2 (`variant.py`)

Условие: найти слова, заканчивающиеся на букву «я», вывести их в нижнем регистре и посчитать количество.

| Входные данные | Ожидаемый результат | Фактический результат |
|---|---|---|
| `Анна, армия! Я читаю.` | `армия`, `я`; Количество: 2 | `армия`, `я`; Количество: 2 |
| `Привет, мир!` | Нет совпадений; Количество: 0 | Нет совпадений; Количество: 0 |
| `!!!` | Нет совпадений; Количество: 0 | Нет совпадений; Количество: 0 |
| Пустая строка | Нет совпадений; Количество: 0 | Нет совпадений; Количество: 0 |

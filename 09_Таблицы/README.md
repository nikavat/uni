# Лабораторная работа № 9. Вложенные списки и таблицы

## Цель работы

Изучить работу с вложенными списками в Python, научиться обрабатывать двумерные таблицы с помощью вложенных циклов,
вычислять суммы элементов строк и столбцов, создавать таблицы по заданным условиям и выполнять преобразования матриц без
изменения исходных данных.

## 1. Суммы строк - `table.py`

Назначение: вычисление суммы элементов каждой строки матрицы. Результаты сохраняются в отдельный список. Для пустой
матрицы возвращается пустой список.

| Тип проверки | Входные данные           | Ожидаемый результат | Фактический результат |
|--------------|--------------------------|---------------------|-----------------------|
| Обычный      | `[[1, 2, 3], [4, 5, 6]]` | `[6, 15]`           | Совпадает с ожидаемым |
| Граничный    | `[[7]]`                  | `[7]`               | Совпадает с ожидаемым |
| Специальный  | `[[1], [-1], [0]]`       | `[1, -1, 0]`        | Совпадает с ожидаемым |
| Специальный  | `[]`                     | `[]`                | Совпадает с ожидаемым |

## 2. Суммы столбцов - `table.py`

Назначение: вычисление суммы элементов каждого столбца матрицы с использованием вложенных циклов. Для пустой матрицы
возвращается пустой список.

| Тип проверки | Входные данные           | Ожидаемый результат | Фактический результат |
|--------------|--------------------------|---------------------|-----------------------|
| Обычный      | `[[1, 2, 3], [4, 5, 6]]` | `[5, 7, 9]`         | Совпадает с ожидаемым |
| Граничный    | `[[7]]`                  | `[7]`               | Совпадает с ожидаемым |
| Специальный  | `[[1], [-1], [0]]`       | `[0]`               | Совпадает с ожидаемым |
| Специальный  | `[]`                     | `[]`                | Совпадает с ожидаемым |

## 3. Диагональный узор - `table.py`

Назначение: создание квадратной матрицы заданного размера. На главной диагонали располагаются нули, выше неё — единицы,
ниже — двойки.

| Тип проверки | Входные данные | Ожидаемый результат                 | Фактический результат |
|--------------|----------------|-------------------------------------|-----------------------|
| Граничный    | Размер `1`     | `[[0]]`                             | Совпадает с ожидаемым |
| Обычный      | Размер `3`     | `[[0, 1, 1], [2, 0, 1], [2, 2, 0]]` | Совпадает с ожидаемым |

## 4. Индивидуальный вариант № 2 - `table.py`

Назначение: преобразование двумерной матрицы по индивидуальному варианту № 2. Все положительные элементы заменяются
единицами, отрицательные элементы и нули остаются без изменений. Функция создаёт новую матрицу той же формы, не изменяя
исходную.

| Тип проверки | Входные данные                   | Ожидаемый результат                     | Фактический результат |
|--------------|----------------------------------|-----------------------------------------|-----------------------|
| Обычный      | `[[-2, 0, 3], [4, -5, 6]]`       | `[[-2, 0, 1], [1, -5, 1]]`              | Совпадает с ожидаемым |
| Граничный    | `[]`                             | `[]`                                    | Совпадает с ожидаемым |
| Специальный  | Изменение элемента новой матрицы | Исходная матрица остаётся без изменений | Совпадает с ожидаемым |
